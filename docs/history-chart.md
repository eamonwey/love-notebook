# 可滑动的历史追踪图

- 时间轴左旧右新，默认定位右端最新记录，一屏约7期。不显示“回到最新”“已到最早记录”等按钮。
- 每页读取21期，以 `beforeIndex` 为游标，向右拖动、到达左侧边界后自动加载更早记录，不再以最近100期为查看上限。加载失败可重试，请求锁避免连续触底重复请求。
- 补入旧数据后按新增节点宽度补偿滚动位置。画布始终只有一屏大，仅绘制可见区域附近节点，不创建无限宽画布。
- 中断期保留暂停断点。拖动不会作为事件标记点击。
- 图表起点的裁剪框覆盖圆点完整描边，标签/事件允许1px布局误差；停靠及滚动结束读取原生scrollOffset重画，过期查询不能覆盖新的滚动位置。页面方向说明与导出图底部解释已移除。
- 黄色数字为该周期事件总数。点击后按周期读取事件，每次最多50条，可以继续加载，避免旧事件被全局最近200条的限制隐藏。
- 右上角“全屏”进入独立横屏页面；两页共用 `utils/history-page.js`，使用真实视口尺寸、设备像素比与安全区域，图表滑动仍只绘制单屏。全屏中点击黄色数字显示居中、不透明的事件弹窗，内容可滚动。关闭后重新获取画布节点，避免原生画布盖住弹窗。
- 导出会独立分页读取全部历史，不使用当前可见窗口或已加载列表。12个点一行，相邻行重叠一个端点，保留全部折线段及暂停断点；每张最多6行（1120×2852像素），超过后自动生成连续多张，预览明确显示总张数。可上下浏览长图、点击放大、分享当前张或保存全部。
- 预览根据图片宽高比及视口计算高度，短图贴合内容，长图限高滚动；横竖屏和切换图片后重新测量。导出图使用独立的14px坐标/期数字号、22px标题，不影响交互图字号；每行按实际点数铺满宽度。
- 导出只含期数、双方分数、暂停断点，不带笔记、批注、事件正文或用户标识。分页异常或生成失败不展示不完整结果；相册拒绝授权时提示打开设置。
- 部署 `track` 云函数，更新小程序。无需新集合；历史及事件查询涉及 `cycles(pairId,status,index)`、`events(pairId,cycleId,_id)`（非交换周期事件还校验作者），按控制台提示配置复合索引。

本轮前端改动重新编译即可；前提是此前支持分页的 `track` 已部署。本地验证包含250期完整导出（249个相邻线段无遗漏）、120条单期事件分页、重复加载锁、位置保持及暂停断线，并对667×320、812×375及1024×768检查浏览器布局。浏览器预览不能代替微信原生运行；需在iOS/Android真机验证横屏进入/退出、安全区、scroll-view与canvas叠层、事件触点、分享、首次相册授权及拒绝后恢复。
